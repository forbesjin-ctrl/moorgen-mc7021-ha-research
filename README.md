# Moorgen MC7021 × Home Assistant

业主共同研究保留 **MC7021 主机和原面板** 的 Home Assistant 接入方式。首个目标只有一组普通灯：能明确开/关，并在原面板操作或重连后取得独立状态。

**v0.2.0 已支持“采样 → 自动离线分析 → 中文报告 → 接入证据核对”。当前是研究工具，尚不是可安装的 Home Assistant/HACS 集成。** 尚无在本项目登记的住户实测兼容组合。采样完成、执行 ACK 或 App 按钮变色均不等于真实灯状态已验证。

这是业主自发项目，非厂家项目。代码和文档公开，住户原始抓包只私下提交。

## 业主怎样参加

下载**整个项目ZIP并完整解压**，在Finder双击根目录 **[打开研究工具.command](打开研究工具.command)**，看到的是中文终端菜单。不要双击`tools/`里的`.py`源码，聊天/网页点文件通常只会预览代码。若`.command`也被编辑器打开，右键选择“打开方式 → 终端”；若系统拦截或缺工具，保留提示，不关闭安全保护。

- **选2：完整离线演示。** 不用手机、不填IP/UDID、不提权；程序生成明确标为合成的PCAP和事件，自动分析并在浏览器打开本地中文报告。这些数据不来自任何住宅。
- **选3：分析已有样本。** 把含`session.json`、`events.jsonl`、`traffic.pcap`的完整结果文件夹拖进终端，回车。原件只读，无需手机或管理员权限。
- **选1：真实采样并自动分析。** 适用于下面列出的现场条件；结束清理后自动生成私有报告。

先找一位在自己家、主机明确为MC7021、原厂App和面板本来就能正常控制普通灯的业主，使用Mac、iPhone和USB数据线采样。只操作同一组普通灯，不扫描设备、不改主机/面板/路由器配置，不涉及场景、总断电或安防。

选1或使用保留的 **[开始单灯采样.command](开始单灯采样.command)** 入口。只填自己主机当前IP与iPhone UDID；按提示正常操作，回车和数字记录实际灯与App显示。系统需要一次Mac管理员授权，密码不会进入日志。Mac需已有Python3和Apple的rvictl；缺少时停止，不自动安装。离线演示和分析不需要rvictl。

结果仅存在本机 `captures/`，没有上传功能。每户样本分别标记，先只公开匿名现象和版本组合。原始PCAP可能含认证及会话信息，不上传Issue、PR或业主群。详见[采样操作](docs/CAPTURE.md)和[私下提交样本](docs/PRIVATE_SAMPLES.md)。

## 采集后能得到什么

报告放在本机`private_reports/analysis_…/`，中文`报告.html`可用浏览器直接打开，包含：

- PCAP大小/哈希、截断/丢包、步骤覆盖和时间对齐检查；不支持或未读成功的包数显示未知。
- 按操作窗口列出开关请求、执行应答、ACK、状态和用户观察；窗口关联不自动声称因果。
- TCP分段/乱序重组、重传去重、缺口和冲突提示；UDP按数据报独立解析，不扫描字节猜帧。
- 反复App开关中的完整设备标识候选，以及面板操作和重进App窗口的状态记录；默认不按设备名猜普通灯类型。
- 会话/认证、实际灯路、独立状态和HA原型仍缺什么；`HA接入待验证.json`明确留空线上参数，不能直接加载为HA配置。

同时生成固定字段的`匿名摘要.json`，只含合成/真实来源声明、数量和质量级别；没有IP、设备标识、时间、路径或原始报文。它仍需本人审阅再手动分享。**完整HTML、report.json及原始样本都保持私下处理，不上传公开仓库。** 详见[采集后的完整流程与边界](docs/AFTER_CAPTURE.md)。

## 程序员可以做什么

- 核对明文帧、TLV、设备类型和状态语义，补充合成测试；从真实样本得出的结论注明匿名来源和版本组合。
- 分别验证认证/加密、目标完整标识、初次同步、面板变化、刷新回读与重连。
- 在证据足够后实现一个普通灯HA原型，状态来自已确认的设备报告；断线或未知时不可假定已成功。
- 复用`tools/light_state_model.py`的纯离线状态内核：ACK不改亮灭，重连等待新会话独立报告，超时变为不可用。该模块没有网络、HA依赖或真实控制能力。

当前工具没有网络控制或重放接口。`tools/offline_shcp.py`只解析本地应用层HEX，也可在内存生成合成候选帧；它不是PCAP解析器，生成的字节不会发送。配置偏移和内部引用不能当通信地址，Mo-Bus或9000端口不能直接等同标准Modbus。

## 离线运行

工具仅依赖Python标准库。真实采样支持Mac；离线解析和测试可在有Python3.9+的Mac/Linux运行。

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
python3 tools/check_public_tree.py
```

不接手机的完整合成演示：

```sh
python3 tools/research_tool.py --demo
```

分析已有采样文件夹：

```sh
python3 tools/research_tool.py --session-dir '/path/to/local/session'
```

旧的纯提示演练仍可用（不生成PCAP）：

```sh
python3 tools/capture_mc7021_light.py --demo
```

演练结果放在`demo_runs/`，完整合成演示会生成**合成**PCAP，旧纯提示演练不生成PCAP。报告另存`private_reports/`。这些目录被Git忽略，公开清单检查还会拒绝跟踪原始抓包、日志和未知文件。不要为分享报告而强行加入Git。
