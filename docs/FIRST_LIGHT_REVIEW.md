# 首组报文核对：自动整理证据，人工确认对应关系

v0.5.0在采样结束或分析已有样本后，自动生成首组检查。报告中“已确认”只表示工具能检查的文件和记录结构事实；“待验证”表示协议解释、设备类型、实际灯路与物理状态仍须核对；“需补采”给出缺失、冲突及建议补采步骤。程序不会因报告生成、ACK、候选数量或合成测试成功而宣布首组通过。

## 操作者看到什么

第一组仍只选能清楚观察亮灭的普通开关灯。完成App开关各两次、面板开关及关闭App后面板改变再重进读状态，结束保存并等待清理完成。界面自动显示首组检查，然后到“首组核对”页查看五项结果、候选完整标识和证据引用。

可以由具备分析能力的业主自行复核，也可请协助分析者结合原件与现场观察核对，不必等待指定人员。先看机器列出的缺口，再逐项查看原始帧、连接方向、动作窗口与观察记录。帧在动作窗口附近仅为关联候选，不自动证明因果。

五项人工结论各自选择“已确认、待验证或需补采”，并填写依据，明确核对的是哪个完整对象候选，再点“保存逐项核对并检查结论”。没有把握就保留待验证，记录疑问；需要补样本就保存需补采结论，以同一灯名补齐证据。自动检查证据不足或有未排除的矛盾时，不能用全部选择已确认覆盖缺口。

## 五项核对内容

1. **样本质量**：原件可读，PCAP大小与采样摘要哈希一致；步骤、事件与报文属于同一轮。核对截断、丢包、TCP序号缺口、未知封装和加密载荷是否影响判断。机器不能验证住宅身份及现场操作本身，仍需人工检查捕获条件。
2. **对象身份**：两次App开、两次App关稳定指向同一完整对象候选，并与本轮实际灯路对应，没有未排除的其他对象。灯名、房间、配置文件偏移和内部引用不能作为通信地址；相同标识或标签也不能自动证明物理身份。
3. **开关含义**：重复操作中的开与关有一致、可解释的字段差异，方向和事件对应无矛盾。区分请求、执行应答、ACK及独立状态；保留会话、计数和序号等未知条件，不把抓到的一段字节当可重放命令。
4. **面板反馈**：用同一实体键改变灯后，来自主机的独立状态候选与肉眼亮灭及App显示一致。人工核对来源是推送还是正常查询回读，排除ACK、执行应答、缓存、周期轮询与其他操作。只抓到ACK就保持待验证或需补采。
5. **重进App回读**：正常关闭手机上的摩根App，用面板改变这组灯后再进入；抓包能支持读取了当前状态，并与肉眼一致，不能沿用关闭前显示。RVI看不到App关闭期间的面板总线不等于面板失效；重点核对重进后的独立回读。

自动工具能给出文件事实、候选标识、帧号及缺口，不能替代协议解释和实际灯路核对。合成演练可体验报告和复核页面，但永远不能保存首组真实通过记录或解锁其他灯。

## 通过记录与后续选择

仅当真实样本的自动证据条件满足、五项人工结论完整且当前原件未变化时，工具允许保存首组通过记录。该记录是本轮证据的**人工复核声明**，不认证业主或住宅身份，也不把`physical_feedback_verified`或HA可用标记改为真；认证、主动控制、面板同步、掉线不可用与重连回读仍需后续单独验证。

记录保存在选择的数据文件夹内，包含私有复核依据、对象候选及本轮原件SHA256绑定。重新打开应用可恢复，但每次开始其他灯前仍检查原件是否存在且哈希相同、当前主机是否匹配和清理是否完成。文件被替换、标签变化或同字节对象都不能自动转移物理身份结论。旧版单一首组声明勾选框不再作为解锁条件。

通过后，可继续同一已知MC7021下的其他普通灯逐组采样，也可点“进入HA接入阶段”。后续普通灯每轮只操作一组、单独记录并结束清理。遇到新的对象冲突、状态矛盾或质量问题时先停止扩展、保留失败与未知。调光、窗帘、暖通和场景不直接套用普通灯解释。

“HA接入”页提供“生成私有HA接入研究包”。应用再次验证真实通过记录与绑定原件，然后在本机整理私有报告、复核记录、原件索引及离线状态内核；认证、控制命令等协议参数保持留空，不猜测、不连接设备。可用“载入已保存核对记录…”恢复记录后继续，失效或未通过记录不能生成通过证据包。

该包让后续分析者和开发者接续研究连接认证、单灯主动开关、独立状态、断线不可用、重连回读及单灯现场验收，不是可安装集成，也不代表HA已可控制灯具。首组人工核对完成，只表示已有一轮可继续研究的对应证据。

## 私有文件与回传

每次离线分析生成`report.json`、`报告.html`、`首组核对.json`、`匿名摘要.json`及`HA接入待验证.json`。首组三类结果和证据也在总报告中显示，独立`首组核对.json`便于后续继续分析。人工复核记录另存本机并绑定原件，不改写采样文件。旧报告缺字段时显示未知，请用新版重新分析同一份原件。

完整报表、原始PCAP、事件、灯名、房间、标识和人工备注均为私有资料。采完把本轮完整采样文件夹及对应报告、复核记录通过事先约定的私下方式回传；不在业主群、GitHub Issue或公开仓库上传。匿名摘要继续只含固定汇总字段，不复制人工备注、对象、灯名、房间或住宅信息，分享前仍由本人审阅。工具没有自动上传或接收服务。

## 当前证据边界

住户真实通信样本仍为0，真实USB采样与系统管理员授权尚未现场验证，Intel和macOS12真机尚未验证，应用尚未Apple公证。离线与合成测试只验证软件流程。Mo-Bus、MC7021名称和9000端口均不足以认定标准Modbus；当前没有已验证的住户控制指令，也没有可直接安装的HA集成。工具不扫描设备、不写未知参数、不恢复配置、不操作安防。
