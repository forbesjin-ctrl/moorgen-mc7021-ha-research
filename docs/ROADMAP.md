# 阶段目标

## 已有：可共同工作的研究基础

v0.3.0新增原生Mac应用、内置双架构Python、JSON交互worker和限定用途采样监督器。演示/分析/报告无需终端，采样使用系统授权及按钮向导。GUI和离线分析可做合成验证；管理员授权与USB采样仍未现场验证，不据此宣称兼容。

v0.2.0已有统一菜单、采样后自动离线分析、PCAP封装读取、TCP重组、事件窗口/设备/状态候选、私有中文HTML报告、固定匿名汇总、HA待验证清单，以及纯离线状态内核。完整合成演示不需要现场或手机。尚无住户原始样本或HA运行验证；当前不提供在线控制客户端。

## 下一阶段：一组普通灯证据闭环

先由一位自愿业主在自己的正常系统记录App开关、面板开关和重进App。离线确认连接会话、完整对象标识/类型、命令差异及独立状态，形成最小匿名结论。再由另一位同型号业主复现并保留版本差异。

## 再下一阶段：单灯HA原型

在对应参与者另行安排的实机验证中，只实现这一组灯。原主机/面板继续工作；HA状态来源必须是独立报告/已核对回读，面板改变后同步，重连读当前状态，断线标为不可用。命令发出或ACK本身不乐观改为已成功。

## 稳定后才考虑扩展

先处理认证、会话过期、丢包、缓存、重连和版本差异，再评估其它普通灯。调光、场景、全屋控制、门锁/暖通和安防不属于首阶段；新范围需独立证据和目标，不随意复用字节。
