# 兼容性记录

当前没有在本公开项目登记的住户实测组合。工具离线测试通过、原厂程序有某个分支、其它项目有样本，均不表示MC7021实机已经支持。

每个新条目按匿名样本编号记录：

- 主机型号及可见固件文字；不知道就填未知，不做升级或恢复。
- App平台/版本、手机系统；原先正常的本地控制是否可用。
- 协议及认证/加密分支的实际可见范围，不公开账号、令牌、地址、标识或密钥。
- 一组普通灯的App开关、面板开关、自动更新/刷新回读及重进App结果。
- 实际灯与主机报告是否一致；未测的环节保留未测，不用执行ACK替代状态。
- 相同匿名编号的私下原件由谁保留；公开只给结论，不在Issue附原件。

同一型号、不同固件/App版本分别登记。来自不同住宅的标识和参数不得互相套用；若两个版本行为不同，保留差异，不用名称相似或同为9000端口合并。

待有数据后，以“仅静态证据／离线样本复现／单户实测／独立多户复现”注明证据来源，不采用笼统的“支持摩根全系”。
