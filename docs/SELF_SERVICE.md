# 业主本地自助：需要会什么

目标是让具备电脑和HA基础的业主，在自己的环境完成采样、本地报文分析、导入可信驱动、安装和单灯验收，不用写Python，不要求把原始资料交给本项目。v0.7.0的[本机适配工作台](LOCAL_ADAPTATION.md)让没有现成驱动的业主也能图形选择真实样本、生成私有编解码配方，并用不同PCAP作第二轮离线对照；不要求首组先通过。**已有经过验证且与本户证据匹配的完整驱动，才可能继续HA在线接入。** 当前真实住户样本与已验证摩根驱动均为0，工具不输出未知协议的可执行驱动，也不承诺自动完成未知登录或实灯控制。

## 五项基础能力

1. **认准现场和灯路。** 人在本户，认得MC7021和同一组普通灯，原厂App及面板原本就能正常控制。
2. **取得已有信息。** 能从现有App、路由器记录或安装资料确认当前IP，从Finder复制iPhone UDID；不知道就停，不猜、不扫描。
3. **管理本地文件。** 会下载、完整解压、选择数据目录、保存原件及导入清单和诊断；知道抓包、标识和完整报告属于本户私有资料。
4. **维护自己的HA。** 已有可用HA，能备份，通过已有文件管理工具复制集成、重启和添加集成。不要求使用终端，也不要求借此安装HA或附加组件。
5. **按实物验收。** 能分别记录灯实际亮灭与HA显示，按提示完成重复开关、面板操作、此适配断开和重连；不把按钮变色或ACK当作真实状态。

HA向导第一步的“自助前检查”只是知识自检，不检测网络或设备，不验证驱动，也不授权连接。勾选不替代首组逐项复核、原件哈希、驱动绑定检查或后续单灯启用授权。

## 三个停止条件

1. **在线材料不具备或不匹配。** 没有适配驱动，首组仍待验证，或来源、版本、主机、对象、清单及哈希不匹配时，停止在线安装和启用，不改标识、参数或校验值绕过。可以继续本机工作台的只读离线研究；离线codec一致不会解除在线限制。
2. **操作条件不成立。** 不知道IP、原厂App不可用、抓包组件缺失、清理状态不明，或HA没有备份/文件管理条件、已有同名目录冲突时，先解决该项。不关闭系统保护，不盲目覆盖。
3. **证据与实物不一致。** 控制错灯、只有ACK、面板状态不更新、断线仍显示可用、重连恢复旧缓存时，保持待验证或需重测，只补当前一组，不扩展其它灯。

## 基础使用与协议开发分开

没有匹配驱动时，普通业主可点“没有匹配驱动：本机分析…”，选择本地完整采样目录，从下拉列表认准完整对象，再点“生成编解码配方并离线核对”；第二轮选另一份PCAP作离线对照。这条路径只需管理本地文件、认准灯路并记录实物，不要求已有HA、写Python或先通过首组。没有样本可选“演示本机适配”。认证/加密、请求、重连或序号策略未知时，`online_ready`保持`false`，根据提示补采同一组正常操作。

普通业主在HA向导第二步点“导入可信驱动材料…”，选择完整清单JSON和驱动Python文件即可；选择文件不等于编程。安装前阅读来源、用途和测试说明，在HA确认信任此版本，并另行明确授权本组普通灯测试。文件选择和静态检查都不证明代码安全或协议正确。

“显示协议开发者工具（普通业主无需）”中的接口模板、四项协议证据及手工清单属于高级路线。实现超出固定codec支持范围的会话与认证、编写完整联网驱动及测试，仍需要协议和开发能力，不能靠基础自检或勾选替代。未来完整且经过验证的会话策略内置后，才可由固定模板生成驱动，无需业主写Python。遇到未知协议分支，可由业主自己选择可信技术协助，在自己控制的环境处理；不要求经过本项目人员。

原始抓包、完整报告、适配配方与对照结果、驱动绑定材料和HA诊断默认留在本户，应用不自动上传。求助及分享均由业主主动选择最少范围；使用云端AI或远程协助前自行确认第三方会接触哪些资料。正式操作见[Mac图形版](MAC_GUI.md)、[本机适配工作台](LOCAL_ADAPTATION.md)和[单灯HA向导](HA_WIZARD.md)。
